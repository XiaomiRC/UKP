# UKP Investigator

Browser-only billing reconciliation and investigation. Select individual files, folders, or ZIPs; processing happens locally in WebAssembly. No end-user software installation is required.

See [browser/README.md](browser/README.md) for build and GitHub Pages deployment instructions. The manual GitHub Actions workflow builds and deploys only static application assets.

Customer inputs, datasets, generated reports, caches, and credentials are excluded.
